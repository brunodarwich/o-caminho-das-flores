# Estudos visuais do Marco 2

- `desktop/`: quatro imagens finais das telas em formato paisagem.
- `mobile/`: quatro versões finais para celular.
- `rascunhos/`: tentativas descartadas, preservadas apenas como histórico. O arquivo `wiki-peinha-incorreta.png` contém uma representação incorreta da Peinha e não deve ser usado como referência de personagem.

Esses PNGs documentam a direção visual. A página em `frontend/` usa a logo e os quadrinhos originais, além da textura neutra em `frontend/assets/backgrounds/`. Fotos finais enviadas por Bruno devem entrar em `frontend/assets/photos/`.
