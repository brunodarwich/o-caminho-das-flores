## 1. Estratégia de Monetização em Fases

Para maximizar a difusão da obra autoral e criar uma comunidade engajada antes de impor barreiras de pagamento, o projeto adota uma estratégia gradual e ética:

```
┌────────────────────────────────────────────────────────┐
│             FASE 1: MVP & TRAÇÃO DE AUDIÊNCIA          │
│       • Acesso 100% Gratuito aos Capítulos 1 e 2       │
│       • Quebra-cabeça e Wiki livres para degustação    │
│       • Custo operacional R$ 0 (GitHub + Vercel)       │
└──────────────────────────┬─────────────────────────────┘
                           │ Crescimento da base de leitores
                           ▼
┌────────────────────────────────────────────────────────┐
│             FASE 2: MONETIZAÇÃO COMUNITÁRIA            │
│  ┌───────────────────────────┐   ┌──────────────────┐  │
│  │   BRASIL (BRL - PIX)      │   │  GLOBAL (USD)    │  │
│  │   • Apoia.se / Catarse    │   │  • Patreon       │  │
│  │   • Chave Pix Direta      │   │  • Stripe        │  │
│  └───────────────────────────┘   └──────────────────┘  │
│       • Capítulos Antecipados (Fast Pass)              │
│       • Wallpapers e Artbooks em Alta Resolução        │
│       • Nome nos créditos oficiais dos capítulos       │
└──────────────────────────┬─────────────────────────────┘
                           │ Consolidação da IP
                           ▼
┌────────────────────────────────────────────────────────┐
│             FASE 3: MERCHANDISING & FÍSICO             │
│       • Livro impresso especial (encadernado)          │
│       • Prints botânicos autografados e baralhos       │
└────────────────────────────────────────────────────────┘
```

## 2. Estrutura de Apoio e Tiers Futuros

| Tier / Plano | Preço Brasil (BRL) | Preço Global (USD) | Benefícios e Recompensas |
|---|---|---|---|
| **Leitor Livre (Free)** | R$ 0 / mês | $ 0 / mo | Acesso livre e irrestrito a todos os capítulos lançados publicamente, wiki e quebra-cabeças. |
| **Apoiador Botânico** | R$ 15,00 / mês | $ 3.50 / mo | Acesso antecipado a novos capítulos (Fast Pass), wallpapers exclusivos para celular/desktop e nome nos agradecimentos ao fim do capítulo. |
| **Mestre Jardineiro (VIP)** | R$ 39,00 / mês | $ 9.00 / mo | Todos os benefícios anteriores + artes conceituais inéditas comentadas pelo autor, minijogos exclusivos e desconto em produtos físicos futuros. |

## 3. Custos Operacionais vs. Margem

### Custos Operacionais do MVP (Fase Atual)
- **Hospedagem & CDN de Imagens**: R$ 0,00 / mês (Vercel / GitHub Pages).
- **Backend & APIs**: R$ 0,00 / mês (Ambiente local / Render tier free).
- **Domínio Personalizado (Opcional)**: ~R$ 40,00 / ano (~R$ 3,33 / mês).
- **Custo Total Fixo Mensal**: ~R$ 0 a R$ 5,00 / mês.

### Projeção com 100 Apoiadores Ativos
- **Receita Mensal Estimada**: 70 Apoiadores Botânicos (R$ 1.050,00) + 30 Mestres Jardineiros (R$ 1.170,00) = **R$ 2.220,00 / mês**.
- **Taxas de Gateway (Apoia.se/Stripe)**: ~10% (R$ 222,00).
- **Custos de Servidor com Tráfego Alto**: ~R$ 50,00 / mês.
- **Lucro Líquido Operacional**: ~R$ 1.948,00 / mês (**Margem > 87%**).
